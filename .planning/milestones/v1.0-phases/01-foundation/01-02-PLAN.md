Replace the stub `packages/playables-adapter/src/index.ts` with full implementation.

**YouTube Playables protocol**: The host iframe communicates via `window.postMessage`. The game listens for messages and responds. When not running inside YouTube (no host detected), fall back to localStorage.

Implementation requirements:

1. **`initPlayables()`**: 
   - Set up `window.addEventListener('message', handler)` 
   - Handler processes messages: `{ type: 'pause' }`, `{ type: 'resume' }`, `{ type: 'load', data: ... }`
   - After init, post `{ type: 'game-ready' }` to `window.parent`
   - Track `_isPlayablesHost` boolean — set true if we receive any message from host within 1s timeout, else false (localStorage mode)

2. **`reportScore(score: number)`**:
   - If Playables host: `window.parent.postMessage({ type: 'score', score }, '*')`
   - Fallback: `localStorage.setItem('arcade-carnival-score', String(score))`

3. **`saveData(key: string, value: string)`**:
   - If Playables host: `window.parent.postMessage({ type: 'save', key, value }, '*')`
   - Fallback: `localStorage.setItem('arcade-carnival-' + key, value)`

4. **`loadData(key: string): string | null`**:
   - If Playables host: return from cached data received via `load` message
   - Fallback: `localStorage.getItem('arcade-carnival-' + key)`

5. **`onPause(cb: () => void)` / `onResume(cb: () => void)`**:
   - Store callbacks in module-level arrays
   - Invoke all registered callbacks when corresponding message received

All functions must be typed with no `any`. Use a module-level `_dataCache: Map<string, string>` for Playables-loaded data. Use `_pauseCallbacks: Array<() => void>` and `_resumeCallbacks: Array<() => void>` for lifecycle hooks.

**`packages/game-engine/src/GameLoop.ts`:**

```typescript
export interface GameScene {
  update(dt: number): void;
  render(ctx: CanvasRenderingContext2D): void;
}
```

- Constructor takes `HTMLCanvasElement`
- Fixed timestep: `TICK_RATE = 1000 / 60` (60fps)
- `start()`: begins `requestAnimationFrame` loop
- `stop()`: cancels animation frame via stored ID
- Loop accumulates elapsed time, calls `update(dt)` per tick, then `render(ctx)` once per frame
- Accepts a `GameScene` object via `setScene(scene: GameScene)` method
- Canvas auto-resize: on construction, add `ResizeObserver` on canvas parent — resize canvas to fill parent while maintaining 4:3 aspect ratio (800x600 base). Store scale factor for input coordinate translation.
- Expose `readonly width: number` and `readonly height: number` (logical game resolution, always 800x600)
- Expose `readonly scale: number` for coordinate mapping

**`packages/game-engine/src/InputManager.ts`:**
- Constructor: attach `keydown` and `keyup` listeners to `window`
- Track pressed keys in `Set<string>` (`_pressed`)
- Track just-pressed in `Set<string>` (`_justPressed`) — added on keydown, cleared each frame
- Track just-released in `Set<string>` (`_justReleased`) — added on keyup, cleared each frame
- `isDown(key: string): boolean` — checks `_pressed`
- `justPressed(key: string): boolean` — checks `_justPressed`
- `justReleased(key: string): boolean` — checks `_justReleased`
- `update(): void` — clears `_justPressed` and `_justReleased` (called by GameLoop at start of each frame)
- `destroy(): void` — removes event listeners
- Use `event.code` (not `event.key`) for consistent layout-independent input

**`packages/game-engine/src/SceneManager.ts`:**
- Internal stack: `_scenes: string[]`
- `push(scene: string): void` — pushes to stack
- `pop(): string | undefined` — pops from stack
- `current(): string | null` — returns top of stack or null
- `replace(scene: string): void` — pops then pushes
- `clear(): void` — empties stack
