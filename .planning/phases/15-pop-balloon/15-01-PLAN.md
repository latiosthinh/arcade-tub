  <behavior>
    - PopEngine:
      - Evaluates click/touch point `(px, py)` against active balloons (top-most z-order / nearest).
      - On pop:
        - If regular balloon: calculates combo chain (if same color as last popped, or if rainbow, increment combo streak and reset combo timer window e.g. 1.8s; if different color, reset streak to 1).
        - Multiplier math: `1 + (streak - 1) * 0.5` (max 5.0x).
        - If bomb: resets combo streak, applies bomb penalty (e.g. -300 points, -5 seconds time penalty, triggers bomb explosion event).
    - GameState:
      - Manages 60-second countdown round timer.
      - Status: `ready` -> `playing` -> `paused` -> `gameover`.
      - Tracks `score`, `highScore`, `streak`, `maxStreak`, `balloonsPopped`, `bombsHit`, `timeRemaining`.
      - Updates time delta, triggers game over when `timeRemaining <= 0`.
      - Persists high score via `saveData('pop-balloon-highscore')` and reports score via `reportScore()`.
  </behavior>
  <action>
    1. Implement `PopEngine.ts`:
       - `handleClick(px: number, py: number, balloons: Balloon[]): PopResult | null`
       - `PopResult`: `{ balloon: Balloon; pointsAwarded: number; streak: number; multiplier: number; isBomb: boolean; isRainbow: boolean; }`
       - Combo timer tracking (`comboTimeRemaining: number`, `comboWindow: number = 1.8`).
       - Method `update(dt: number)` to tick down combo timer and reset streak on timeout.
    2. Implement `GameState.ts`:
       - `export type GameStatus = 'ready' | 'playing' | 'paused' | 'gameover';`
       - Constants: `ROUND_DURATION = 60.0`, `STORAGE_KEY = 'pop-balloon-highscore'`, `BOMB_TIME_PENALTY = 5.0`, `BOMB_SCORE_PENALTY = 300`.
       - High score loading on constructor, `start()`, `update(dt)`, `recordPop(result: PopResult)`, `pause()`, `resume()`, `restart()`, `finalizeGame()`.
    3. Write unit tests in `games/pop-balloon/test/popengine.test.ts` and `games/pop-balloon/test/gamestate.test.ts` testing:
       - Multi-balloon overlap picking top/nearest balloon.
       - Same-color combo chaining and multiplier scaling.
       - Rainbow wildcard combo maintenance.
       - Combo window expiration.
       - Bomb hit penalty (score and time deduction) and combo breaking.
       - 60s timer countdown, pause/resume, and high score persistence.
