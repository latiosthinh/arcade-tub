      - `getDimples()`: returns array of dimple cells (id, x, y, radius, row, color, isPopped, popDepth).
      - `popDimpleAt(x, y, hitRadius)`: tests hit detection against dimple centers in current orientation; toggles `isPopped` state if valid; returns toggled dimple or null.

      - `isAllPopped()`: returns true if all dimples in current facing direction are popped.
      - `resetBoard()`: unpops all dimples.
    - PopIt.test.ts:
      - All board shapes initialize with correct dimple counts and valid coordinates.
      - Tapping unpopped dimple pushes it down (`isPopped: true`).
      - Tapping already-popped dimple on same face does not re-trigger.
      - Flipping board mirrors coordinates and permits popping dimples from reverse side.
      - `isAllPopped` correctly identifies when all dimples on active face have been pressed.
  </behavior>
