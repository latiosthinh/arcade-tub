  <behavior>
    - Grid2048:
      - Types:
        - `Direction = 'up' | 'down' | 'left' | 'right'`
        - `TileMoveEvent = { fromRow: number; fromCol: number; toRow: number; toCol: number; value: number }`
        - `TileMergeEvent = { row: number; col: number; value: number; fromCells: Array<{ row: number; col: number }> }`
        - `SlideResult = { moved: boolean; scoreGained: number; moves: TileMoveEvent[]; merges: TileMergeEvent[]; spawnedTile?: { row: number; col: number; value: number } }`
      - Grid representation:
        - 4x4 numeric matrix (`cells: number[][]`, where 0 denotes empty cell).
      - Core Methods:
        - `getCells(): number[][]`: Returns clone of current 4x4 matrix.
        - `getCell(r: number, c: number): number`: Returns value at row `r`, col `c`.
        - `setCells(cells: number[][])`: Sets matrix directly (for testing/snapshot restoration).
        - `getEmptyCells(): Array<{ row: number; col: number }>`: Returns array of empty coordinates.
        - `spawnTile(rng?: () => number)`: Selects random empty cell; spawns 2 with 90% probability, 4 with 10% probability. Returns spawned tile info or null if board full.
        - `canMove(): boolean`: Returns true if any empty cell exists or if any adjacent horizontal/vertical cells have matching non-zero values.
        - `canMoveDirection(dir: Direction): boolean`: Returns true if sliding in `dir` would produce any move or merge.
        - `hasWon(target?: number)`: Checks if any cell contains `target` (default 2048).
        - `getMaxTile(): number`: Returns highest tile value currently on board.
        - `slide(dir: Direction, spawnAfter?: boolean, rng?: () => number): SlideResult`:
          - Executes slide and merge according to standard 2048 rules:
            - Slide left: each row compressed to left, adjacent equal numbers merge once per move into double value.
            - Slide right, up, down: symmetric transformations.
          - Calculates score gained (sum of all merged tile values).
          - Emits fine-grained `moves` and `merges` event descriptors for canvas animation interpolation.
          - If `moved` is true and `spawnAfter !== false`, spawns a new 2 or 4 tile in empty cell.
        - `undo()` / `saveSnapshot()`: Maintains history stack of previous boards and scores to support undoing moves.
        - `reset()`: Clears board and spawns 2 initial tiles.
  </behavior>
