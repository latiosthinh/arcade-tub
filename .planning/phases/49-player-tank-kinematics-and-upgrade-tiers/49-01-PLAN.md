  <name>Task 2: Implement PlayerTank Class with Kinematics, Snapping, Ice Drift & Tier Progression</name>
  <files>games/tank-1990/src/PlayerTank.ts</files>
  <action>
    Create `games/tank-1990/src/PlayerTank.ts` implementing `PlayerTank` with the following methods and behaviors:
    1. **Constructor & Spawn Lifecycle**:
       - Accepts `grid: GridMap` and optional initial options (`lives = 3`, `spawnCol = 8`, `spawnRow = 24`, `tier = TankTier.TIER_1`).
       - `spawn()` method places tank at `(spawnCol * 16 + 2, spawnRow * 16 + 2)` (centered inside 32x32 footprint, e.g. 28x28 size at x=130, y=386 or x=128+2, y=384+2), facing `UP`, sets `shieldTimer = SPAWN_SHIELD_DURATION` (3.0s), `isDead = false`, velocity = 0.
       - `respawn()` decrements `lives`, resets `tier = TankTier.TIER_1` (per classic Battle City rules: upgrades reset upon death), and calls `spawn()`. If `lives <= 0`, marks `isGameOver = true`.
    2. **Orthogonal Corner Auto-Alignment Snapping (<= 4px)**:
       - When steering direction changes from horizontal to vertical (or vertical to horizontal):
         - Example: moving LEFT/RIGHT and pressing UP/DOWN: check alignment against 16px grid lines.
         - Calculate offset to nearest 16px sub-tile boundary `remainder = (tank.x) % 16`.
         - If `remainder <= CORNER_SNAP_THRESHOLD (4px)`: snap `tank.x` to `tank.x - remainder`.
         - Else if `16 - remainder <= CORNER_SNAP_THRESHOLD (4px)`: snap `tank.x` to `tank.x + (16 - remainder)`.
         - Apply symmetrical logic for Y axis when changing to horizontal steering.
         - Check collision before applying snap to ensure tank does not snap into a solid wall.
    3. **4-Way Cardinal Movement & Collision Resolution**:
       - `update(dt: number, inputDirection: CardinalDirection | null)`:
       - If dead, update nothing.
       - Shield timer: `shieldTimer = Math.max(0, shieldTimer - dt)`.
       - Check if current position is on `TileType.ICE`: query `grid.queryRect(this.getBounds())`. If `query.isIce`, tank is on ice.
       - **Movement Physics**:
         - If `inputDirection` is non-null:
           - If `inputDirection !== this.direction`, apply corner snapping, then set `this.direction = inputDirection`.
           - Move tank forward along `this.direction` by `speed * dt`.
           - If tank on ICE, maintain slide momentum in current direction (`slideVelocity = speed`).
           - Perform collision check via `grid.queryRect(this.getBounds())`. If `query.solid` (or `query.isWater` and `!this.boatActive`), step back to previous uncollided position or clamp to cell edge.
         - If `inputDirection` is null:
           - If on ICE and `slideVelocity > 0`: drift forward in `this.direction` by `slideVelocity * dt`, decelerating `slideVelocity = Math.max(0, slideVelocity - ICE_SLIDE_DECEL * dt)`. If collision occurs during drift, stop slide (`slideVelocity = 0`) and clamp.
           - If not on ICE, immediately stop (`slideVelocity = 0`).
    4. **Upgrade Tiers & Powerup Modifiers**:
       - `upgradeTier()`: increments `tier` up to `TankTier.TIER_4`. Updates stats (`speed`, `maxBullets`, `canDestroySteel`, `canCutTrees`).
       - `setTier(tier: TankTier)`: direct tier set (for Star/Gun powerups or testing).
       - `setShield(duration: number)`: sets temporary invulnerability (e.g. 10s Helmet powerup).
       - `addLife(amount: number = 1)`: increments `lives`.
       - `kill()`: if `isInvulnerable` (shieldTimer > 0), ignore damage and return false. If vulnerable, set `isDead = true`, return true.
       - `setBoat(active: boolean)`: allows tank to traverse `TileType.WATER`.
    5. **Getters**:
       - `getBounds(): Rect` returns `{ x: this.x, y: this.y, width: 28, height: 28 }`.
       - `getState(): PlayerTankState` returns full snapshot of tank state.
  </action>
