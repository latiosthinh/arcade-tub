  <behavior>
    - WaterSortEngine:
      - `constructor(tubeCapacity = 4)`: initializes game state with array of `Tube` objects (each containing array of color strings up to capacity).
      - `canPour(fromIndex, toIndex)`: validates if pour is legal:
        1. Source tube cannot be empty and destination tube cannot be full.
        2. Source and destination cannot be the same tube.
        3. Destination must be either completely empty OR top color in destination must match top color in source.
      - `getTransferCount(fromIndex, toIndex)`: calculates how many contiguous units of top color can move (min of matching top color run length and remaining capacity in destination).
      - `pour(fromIndex, toIndex)`: transfers units; pushes `MoveRecord` onto `undoStack`; returns move details for animation.
      - `undo()`: pops latest move from `undoStack` and reverses transferred liquid units back into source tube.
      - `isSolved()`: returns true if every tube is either completely empty or full with 4 units of a single matching color.
      - `getTopColor(tubeIndex)`: returns color of uppermost liquid layer.
    - LevelGenerator:
      - `generateLevel(levelNumber)`: scales difficulty based on level (level 1 = 3 tubes/2 colors, level 5 = 6 tubes/4 colors, level 20 = 10 tubes/8 colors; always 2 empty buffer tubes).
      - Generates guaranteed solvable configurations by starting with solved tubes and performing reverse randomized valid pours.
    - LiquidAudio:
      - `playTubeSelect()`: light glass clink sound (2000Hz short ping).
      - `playGlug(unitIndex, totalUnits)`: bubbly resonant water drop audio with pitch stepping up (300Hz, 380Hz, 460Hz, 550Hz) simulating filling vessel.
      - `playPourStream()`: gentle water rushing filter sweep.
      - `playWinChimes()`: ascending pentatonic victory arpeggio on level completion.
    - Unit Tests (`LiquidSort.test.ts`):
      - Test valid pour into empty tube.
      - Test valid pour matching top color.
      - Test rejected pour when colors mismatch.
      - Test rejected pour when destination is full.
      - Test multi-unit contiguous block pouring (e.g. 2 blue units transfer together if space allows).
      - Test undo stack restores exact previous tube states.
      - Test win condition correctly flags completed board vs in-progress board.
      - Test level generator produces valid initial state with expected tube and color counts.
  </behavior>
