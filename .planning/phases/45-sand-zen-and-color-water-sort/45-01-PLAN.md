  <behavior>
    - SandGrid:
      - `constructor(width = 160, height = 120)`: allocates 2D grid storing cell states (empty = 0, wall/obstacle = -1, sand grain = color ID or RGB int).
      - `step()`: iterates bottom-up (alternating left/right scan direction per row to prevent directional bias) applying granular falling rules:
        1. If cell below is empty, move straight down.
        2. Else, check bottom-left and bottom-right diagonals; if empty, slide down diagonally.
        3. If sand piles up steeper than repose angle (diagonal slope), slide sideways/diagonally.
        4. Track count of moving vs resting grains.
      - `addSand(x, y, color, radius = 2, jitter = 0.5)`: adds cluster of sand grains around (x, y) with color variation.
      - `addWall(x1, y1, x2, y2, thickness = 2)`: rasterizes fixed deflector wall / funnel obstacle.
      - `clear()`: clears all sand grains while keeping boundary borders.
      - `getMovingGrainsCount()`: returns number of grains in motion during latest step.
    - ZenTools:
      - `ZenToolType`: `'hopper' | 'rake' | 'funnel' | 'brush' | 'palette'`.
      - `applyRake(grid, x1, y1, x2, y2, rakeWidth = 6, tines = 4)`: carves sinusoidal wave displacement grooves through sand, shifting top grains outward and creating furrow ridges.
      - `placeFunnel(grid, x, y, width = 30, angle = 45)`: builds V-shaped deflector funnel guiding sand grains through a narrow central aperture.
      - `hopperState`: auto-swings horizontally across top or drops continuous sand stream at target location.
    - SandAudio:
      - Continuous granular cascade whisper: pink/brown noise filter modulated by `activeMovingGrains`.
      - Crystal sand chimes: soft pentatonic sine chimes (C4, D4, E4, G4, A4, C5, D5) triggered rhythmically when sand fills basins or flows through funnels.
      - Rake gravel scrape: subtle textured friction audio when dragging rake tool.
    - Unit Tests (`SandZen.test.ts`):
      - Test single sand grain falling straight down onto bottom floor.
      - Test pyramid dune formation and angle of repose when dropping continuous stream onto single point.
      - Test deflector wall stops sand and funnels it diagonally.
      - Test rake displacement moves surface sand without deleting grains.
      - Test grid bounds protection preventing out-of-bounds writes.
  </behavior>
