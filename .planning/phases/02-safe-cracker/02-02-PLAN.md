      - `particles: Particle[] = []`
      - `emit(x: number, y: number, count: number, color: string, speed = 150, size = 3, maxLife = 0.5): void`:
        - Spawns `count` particles with angle `Math.random() * Math.PI * 2` and velocity `speed * (0.5 + Math.random() * 0.5)`.
      - `update(dt: number): void`:
        - Moves particles: `p.x += p.vx * dt`, `p.y += p.vy * dt`, `p.vx *= 0.95`, `p.vy *= 0.95`.
        - Decays life: `p.life -= dt`.
        - Filters out `p.life <= 0`.
      - `render(ctx: CanvasRenderingContext2D): void`:
        - Saves context, draws each particle circle/rect with `globalAlpha = Math.max(0, p.life / p.maxLife)` and `fillStyle = p.color`.
        - Restores context.
      - `clear(): void`: empties particle array.
    Create `games/safe-cracker/test/particles.test.ts` to test emission, movement, decay, and clearing.
  </action>
