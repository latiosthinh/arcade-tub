  <behavior>
    - LawnGrid:
      - `constructor(cols = 40, rows = 30, cellSize = 16)`: builds 2D cell grid (0 = cut turf, 1 = tall grass, 2 = obstacle/fence/flowerbed, -1 = border).
      - `cutRadius(worldX, worldY, radius)`: marks all tall grass cells within radius as cut; returns number of freshly cut cells.
      - `getCutPercentage()`: returns `(totalCutCells / totalCuttableCells) * 100`.
      - `isCleared()`: returns true if `getCutPercentage() >= 99.5%`.
      - `loadLevel(levelIndex)`: generates varied yard designs (Checkerboard, Spiral Labyrinth, Flower Island, Suburban Backyard with stepping stones).
    - MowerVehicle:
      - `constructor(startX, startY)`: manages position (x, y), velocity, heading angle, speed (maxSpeed = 160 px/s), and cutting deck radius.
      - `update(inputVector, dt, grid)`: applies forward thrust in direction of steering angle, turns towards input heading with realistic rotational inertia, checks obstacle collisions and repels vehicle from walls.
      - `getCuttingDeck()`: returns center `(deckX, deckY)` and radius of spinning mower blades.
    - GrassConfetti:
      - `spawn(x, y, headingAngle, count, color)`: ejects curved rectangular ribbon particles backward/sideways with random spin and velocity.
      - `update(dt)`: updates particle physics (drag, gravity, spin rotation, opacity decay).
    - MowerAudio:
      - `updateEngine(speedRatio, isCutting)`: synthesizes buzzing 2-stroke engine (sawtooth oscillator modulated by sub-square vibrato). Increases pitch (from 80Hz idle to 160Hz full throttle) and adds raspy cutting noise when trimming tall grass.
      - `playLevelComplete()`: ascending harp/glockenspiel victory chord.
    - Unit Tests (`GrassMow.test.ts`):
      - Test lawn grid initializes with correct cuttable cell count.
      - Test `cutRadius` turns tall grass to cut turf and returns cut count.
      - Test mower kinematics move forward and turn towards target heading.
      - Test obstacle collision detection stops/slides mower against boundary.
      - Test cut percentage reaches 100% when all cuttable cells are trimmed.
  </behavior>
