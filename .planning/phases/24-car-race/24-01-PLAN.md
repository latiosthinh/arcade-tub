        - `getLaneCenter(laneIndex: number): number` -> returns center X of lane (0 to 3), e.g. lane 0 = 60 + 45 = 105.
        - `getLaneFromX(x: number): number` -> clamps and returns nearest lane index (0-3).

      - State: `x: number`, `y: number` (fixed baseline e.g. y = 560), `speed: number` (km/h, default 150), `targetLane: number`, `currentLane: number`, `steeringDir: number` (-1 for left, 1 for right, 0 for neutral), `isAccelerating: boolean`, `isBraking: boolean`, `alive: boolean = true`, `tiltAngle: number`.
      - Methods:
        - `setThrottle(accelerating: boolean): void`.
        - `setBrake(braking: boolean): void`.
        - `setSteer(dir: number): void` (-1, 0, 1) or `shiftLane(targetLaneIndex: number): void`.
        - `update(dt: number, lanes: HighwayLanes): void`:
          - Speed adjustment:
            - If `isAccelerating`: `speed = Math.min(MAX_SPEED, speed + ACCELERATION * dt)`.
            - Else if `isBraking`: `speed = Math.max(MIN_SPEED, speed - BRAKE_DECELERATION * dt)`.
            - Else: decelerates gently towards base speed (150 km/h).
          - Lateral position adjustment:
            - `x += steeringDir * LATERAL_SPEED * dt`.
            - Clamps `x` to road bounds using `lanes.clampToRoad(x, CAR_WIDTH)`.
            - Updates `currentLane = lanes.getLaneFromX(x)`.
            - Updates `tiltAngle = steeringDir * 0.12` (smoothed lean angle).
        - `getHitbox(): CarHitbox` -> returns `{ x: this.x - CAR_WIDTH/2 + 4, y: this.y - CAR_HEIGHT/2 + 6, width: CAR_WIDTH - 8, height: CAR_HEIGHT - 12 }` (slightly inset for arcade feel).
        - `reset(initialLane: number = 1): void`.

      - Constants: `SPAWN_INTERVAL_BASE = 1.4` (seconds), `MIN_SPAWN_INTERVAL = 0.5`, `DRAFT_DISTANCE_Y = 120`, `DRAFT_LATERAL_MARGIN = 24`.
      - State: `vehicles: TrafficVehicle[]`, `spawnTimer: number`, `nextId: number`.
      - Methods:
        - `spawnVehicle(lanes: HighwayLanes, playerSpeed: number): TrafficVehicle | null`:
          - Selects random lane (0 to 3).
          - Enforces solvable gap invariant: checks all existing vehicles in candidate lane. If top vehicle y < 140, aborts or picks another lane to guarantee no overlapping/unavoidable wall spawns across all 4 lanes.
          - Selects vehicle type (e.g. 50% SEDAN speed 80-100 km/h, 25% TRUCK speed 60-80 km/h width 46 height 100, 15% SPORTS speed 120-140 km/h, 10% POLICE speed 110-130 km/h).
          - Spawns at `y = -100` (off top of screen).
        - `update(dt: number, playerSpeed: number, lanes: HighwayLanes): { passedCount: number }`:
          - Updates each vehicle position based on relative speed: `relativeSpeed = (playerSpeed - vehicle.speed) * (1000 / 3600) * 4.2` (pixels/sec).
          - `vehicle.y += relativeSpeed * dt`.
          - Removes vehicles that scroll below `y > CANVAS_HEIGHT + 120`.
          - Handles dynamic spawn timer scaling with player speed.
        - `checkCollision(playerHitbox: CarHitbox): TrafficVehicle | null` -> returns first vehicle whose AABB intersects player.
        - `checkDrafting(playerHitbox: CarHitbox): { isDrafting: boolean, draftedVehicle: TrafficVehicle | null }`:
          - Returns true if player is directly behind or close alongside a vehicle ahead within drafting zone (`dy < DRAFT_DISTANCE_Y` and `|dx| < DRAFT_LATERAL_MARGIN`).
        - `reset(): void`.

      - Status machine: `GameStatus = 'ready' | 'playing' | 'paused' | 'gameover'`.
      - Scoring & Speed metrics:
        - `distance: number` (meters traveled, `distance += (playerSpeed * 1000 / 3600) * dt`).
        - `score: number`, `highScore: number`, `carsDodged: number`, `draftTime: number`.
        - `draftMultiplier: number` (1.0x up to 3.0x when drafting).
        - `speedMultiplier: number` = `1.0 + (playerSpeed - 100) / 250 * 1.5` (1.0x to 2.5x).
        - `update(dt: number, playerSpeed: number, isDrafting: boolean): void`:
          - Accumulates distance and base score: `score += Math.floor((playerSpeed / 10) * speedMultiplier * (isDrafting ? 2.0 : 1.0) * dt)`.
          - If `isDrafting`: accumulates `draftTime += dt`.
          - Updates high score.
        - `startGame()`, `pause()`, `resume()`, `endGame()`, `reset()`.
