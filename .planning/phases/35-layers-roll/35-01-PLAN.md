# Plan: Phase 35-01 - Layers Roll Papercraft Simulation

## Task 1: Core Physics, Track Hazards & Unit Tests
Create `games/layers-roll/package.json`, `games/layers-roll/tsconfig.json`, `games/layers-roll/src/RollPhysics.ts`, `games/layers-roll/src/TrackGenerator.ts`, `games/layers-roll/src/GameState.ts`.
- Rolling paper roll moving forward with lateral steering (A/D, Left/Right, Touch/Mouse drag).
- Accumulating colored construction paper sheets on the track (expanding roll radius and score value).
- Obstacle trimmer saws and teeth slicing off outermost layers if collided.
- Finish ribbon line cutting mechanic with distance multiplier based on final roll thickness.
- Unit tests in `games/layers-roll/test/` for radius scaling, trimming mechanics, lane steering, and finish score calculation.
