        - `padding: number = 8`
        - `offsetTop: number = 70`
        - `offsetLeft: number = 15`
      - Methods:
        - `loadLevel(level: number): void`:
          - Resets `this.bricks = []`.
          - Generates layouts based on `level`:
            - Level 1: 4 rows standard bricks (cyan `#00d2d3`, magenta `#ff7675`, yellow `#fed330`, green `#26de81`) with 2 bonus bricks and 1 life brick.
            - Level 2: 5 rows with durable bricks (hp=2, indigo `#575fcf`) in front row, bonus bricks, and life brick.
            - Level 3+: 6 rows with alternating durable (hp=3, purple `#8854d0`), durable (hp=2), standard, bonus, and life bricks.
          - Calculates `x = offsetLeft + col * (brickWidth + padding)`, `y = offsetTop + row * (brickHeight + padding)`.
        - `checkBallCollision(ball: Ball): CollisionResult`:
          - Loops through active `bricks` (`!b.destroyed`).
          - Performs circle-to-AABB intersection:
            - Find closest point on rectangle: `closestX = Math.max(b.x, Math.min(ball.x, b.x + b.width))`, `closestY = Math.max(b.y, Math.min(ball.y, b.y + b.height))`.
            - `distanceX = ball.x - closestX`, `distanceY = ball.y - closestY`.
            - `distanceSquared = distanceX * distanceX + distanceY * distanceY`.
            - If `distanceSquared <= ball.radius * ball.radius`:
              - Determine collision normal: compare penetration depths from top/bottom vs left/right.
              - If `Math.abs(distanceX) > Math.abs(distanceY)`: `ball.vx = -ball.vx` (horizontal bounce).
              - Else: `ball.vy = -ball.vy` (vertical bounce).
              - Decrement `b.hp--`.
              - Points calculation:
                - If standard: 5 pts per hit.
                - If durable: 5 pts per hit (total 10 or 15 pts).
                - If bonus: 50 pts when destroyed.
                - If life: 10 pts when destroyed.
              - If `b.hp <= 0`: `b.destroyed = true`.
              - Return `{ hit: true, brick: b, pointsAwarded, isDestroyed: b.destroyed, isBonus: b.type === 'bonus', isLife: b.type === 'life' }`.
          - Return `{ hit: false, pointsAwarded: 0, isDestroyed: false, isBonus: false, isLife: false }`.
        - `isLevelCleared(): boolean`:
          - Returns `this.bricks.every(b => b.destroyed)`.
        - `getRemainingBrickCount(): number`:
          - Returns count of `!b.destroyed`.
