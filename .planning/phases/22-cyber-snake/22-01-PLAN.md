  <behavior>
    - SnakeGrid:
      - Constants: `GRID_COLS = 25`, `GRID_ROWS = 20`, `CELL_SIZE = 32` (canvas logical size: 800 x 640).
      - `isInside(x: number, y: number): boolean` -> returns true if 0 <= x < GRID_COLS and 0 <= y < GRID_ROWS.
      - `gridToPixel(gx: number, gy: number): { x: number, y: number }` -> returns `{ x: gx * CELL_SIZE + CELL_SIZE / 2, y: gy * CELL_SIZE + CELL_SIZE / 2 }` (center of cell) or top-left depending on use.
      - `pixelToGrid(px: number, py: number): { gx: number, gy: number }` -> returns floored grid coordinates.
    - Snake:
      - Direction enum: `UP = 'UP'`, `DOWN = 'DOWN'`, `LEFT = 'LEFT'`, `RIGHT = 'RIGHT'`.
      - Vectors: UP: (0, -1), DOWN: (0, 1), LEFT: (-1, 0), RIGHT: (1, 0).
      - State: `body: Array<{ x: number, y: number }>`, `currentDirection: Direction`, `directionQueue: Direction[]`, `baseStepInterval: number = 0.16` (seconds), `minStepInterval: number = 0.065`, `stepTimer: number = 0`, `growPending: number = 0`, `alive: boolean = true`.
      - Movement & Direction queue:
        - `queueDirection(dir: Direction): void` -> buffers desired direction. Rejects opposite of current moving direction or opposite of last queued direction to prevent 180° immediate self-collision. Buffer max length 2.
        - `setStepInterval(interval: number): void` or dynamic calculation based on length: `getStepInterval(): number` = `Math.max(minStepInterval, baseStepInterval - (body.length - 3) * 0.0025)`.
        - `update(dt: number): { stepped: boolean, head: { x: number, y: number }, tailRemoved?: { x: number, y: number } }` -> accumulates `dt` into `stepTimer`. When timer >= current step interval:
          - Pops next direction from `directionQueue` if present, sets `currentDirection`.
          - Calculates new head `(head.x + dx, head.y + dy)`.
          - Unshifts new head into `body`.
          - If `growPending > 0`, decrements `growPending` (keeps tail). Else pops tail.
          - Resets `stepTimer -= stepInterval`.
        - `grow(amount: number = 1): void` -> increases `growPending += amount`.
        - `checkSelfCollision(): boolean` -> returns true if new head coordinate matches any segment from index 1 to `body.length - 1`.
        - `occupies(x: number, y: number): boolean` -> returns true if coordinate is part of snake body.
        - `reset(startX: number, startY: number, initialLength: number = 3, initialDir: Direction = Direction.RIGHT): void`.
  </behavior>
