  <behavior>
    - SnakeAudio:
      - Uses AudioSynthesizer / Web Audio API (`AudioContext`).
      - Methods:
        - `playTurn()`: Short subtle high-pitch click/tick (e.g. 800Hz sine/triangle blip, 0.03s duration).
        - `playEat(multiplier: number = 1)`: Energetic neon blip/harmonic sweep (frequency scales with combo multiplier, e.g. 520Hz -> 780Hz, 0.08s duration).
        - `playGoldenPickup()`: Ascending arpeggio chime (e.g. 600Hz -> 900Hz -> 1200Hz, 0.2s duration).
        - `playCrash()`: Low frequency noise explosion with rapid downward sweep (e.g. 240Hz down to 40Hz with filtered noise, 0.35s duration).
        - `setMuted(muted: boolean): void`.
    - ParticleSystem:
      - Manages pool of particles (position `x, y`, velocity `vx, vy`, `color`, `size`, `alpha`, `life`, `maxLife`).
      - Methods:
        - `emitFoodBurst(x: number, y: number, color: string, count?: number)`: Radial burst of 12-16 sparkling dots.
        - `emitGoldenBurst(x: number, y: number, count?: number)`: Golden high-energy star/ring burst.
        - `emitCrashExplosion(segments: Array<{ x: number, y: number }>, cellSize: number)`: Disintegrates snake segments into glowing debris particles scattering outwards.
        - `emitStreakSparkles(x: number, y: number, count?: number)`: Floating upward combo sparkles.
        - `update(dt: number)`: Updates position, drag deceleration, fades alpha, removes dead particles.
        - `reset()`: Clears active particle pool.
  </behavior>

       - Alpha decay, movement integration, and dead particle culling.
       - Particle system reset.
