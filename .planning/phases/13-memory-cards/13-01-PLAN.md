    - GameState initializes with status 'ready', score 0, 60s round countdown, streak 0, flipAttempts 0, and loads high score via `loadData('memory-cards-highscore')`.
    - `start()` sets status to 'playing', resets score, resets timer to 60.0s, resets streak to 0, resets flipAttempts to 0.
    - `recordMatch(pairIndex: number)` increments streak, calculates score with combo multiplier: base 500 * combo multiplier (1 + streak * 0.5), increments flipAttempts.

    - `update(dt)` decreases timer; when timer <= 0, sets status to 'gameover', saves high score with `saveData('memory-cards-highscore')` and calls `reportScore(score)`.
