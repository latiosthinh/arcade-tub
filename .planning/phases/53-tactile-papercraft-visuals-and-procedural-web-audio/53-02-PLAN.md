<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser Web Audio Autoplay Policy -> TankAudio | AudioContext creation before user gesture throws or enters suspended state |
| Rapid Sound Triggers -> Web Audio Node Allocation | Rapid-fire sound triggers (e.g. multi-shot explosions) could leak orphaned oscillators/nodes if not disconnected on `onended` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-04 | Denial of Service / Crash | AudioContext Autoplay | mitigate | Wrap AudioContext instantiation in try/catch and resume context lazily on user gesture |
| T-53-05 | Resource Exhaustion / Memory Leak | TankAudio Web Audio Nodes | mitigate | Connect node cleanup handlers (`osc.onended = () => osc.disconnect()`) and stop nodes after duration |
| T-53-06 | Audio Distortion / Clipping | TankAudio Audio Output | mitigate | Route all sound channels through master `DynamicsCompressorNode` before `ctx.destination` (VISUAL-05) |
</threat_model>
