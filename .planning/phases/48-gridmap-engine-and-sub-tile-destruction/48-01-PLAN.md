  <files>games/tank-1990/src/types.ts</files>
  <action>
Create `games/tank-1990/src/types.ts` defining:
1. `TileType`: `EMPTY = 0`, `BRICK = 1`, `STEEL = 2`, `WATER = 3`, `TREES = 4`, `ICE = 5`, `EAGLE = 6`.
2. `SubTileMask`: 4-bit bitmask flags for 8x8px sub-quadrants:
   - `TOP_LEFT = 1 << 0` (0b0001)
   - `TOP_RIGHT = 1 << 1` (0b0010)
   - `BOTTOM_LEFT = 1 << 2` (0b0100)
   - `BOTTOM_RIGHT = 1 << 3` (0b1000)
   - `FULL = 0b1111` (15)
   - `EMPTY = 0b0000` (0)
   - Directional hit bitmask modifiers:
     - Hit from UP (bullet moving DOWN): destroys top half (`TOP_LEFT | TOP_RIGHT`) if present, then bottom half.
     - Hit from DOWN (bullet moving UP): destroys bottom half (`BOTTOM_LEFT | BOTTOM_RIGHT`) if present, then top half.
     - Hit from LEFT (bullet moving RIGHT): destroys left half (`TOP_LEFT | BOTTOM_LEFT`) if present, then right half.
     - Hit from RIGHT (bullet moving LEFT): destroys right half (`TOP_RIGHT | BOTTOM_RIGHT`) if present, then left half.
3. `CardinalDirection`: `'UP' | 'DOWN' | 'LEFT' | 'RIGHT'`.
4. `CellCoord`: `{ col: number; row: number }`.
5. `Rect`: `{ x: number; y: number; width: number; height: number }`.
6. `GridCell`: `{ type: TileType; mask: number; }`.
7. `EagleState`: `{ col: number; row: number; width: number; height: number; destroyed: boolean }`.
8. `TerrainQueryResult`: `{ solid: boolean; bulletSolid: boolean; isWater: boolean; isIce: boolean; isTrees: boolean; isEagle: boolean; cell?: GridCell }`.
  </action>

<task type="auto">
  <name>Task 2: Implement GridMap engine with bitmask chipping, terrain queries, and Eagle HQ</name>
  <files>games/tank-1990/src/GridMap.ts</files>
  <action>
Implement `GridMap` class in `games/tank-1990/src/GridMap.ts`:
1. Constants:
   - `GRID_COLS = 26`, `GRID_ROWS = 26`, `CELL_SIZE = 16`, `ARENA_SIZE = 416` (26 * 16).
   - `SUB_TILE_SIZE = 8` (4 sub-tiles per cell).
2. Internal State:
   - 2D array or 1D Uint8Array / structure storing `GridCell` (`type` and `mask`) for each (col, row).
   - `eagleState`: `EagleState` located at col 12..13, row 24..25 (bottom center, 2x2 cells).
   - `fortificationCache`: Map or array storing cached cells around Eagle HQ when fortified by shovel powerup.
3. Methods:
   - `initEmpty()`: Resets all cells to `EMPTY` (mask 0), Eagle to intact at (12, 24).
   - `getCell(col: number, row: number): GridCell | null`: Out of bounds returns null.
   - `setCell(col: number, row: number, type: TileType, mask?: number): void`: Sets tile type and sub-tile mask (default `0b1111` for BRICK/STEEL/EAGLE, `0` for EMPTY).
   - `damageBrick(col: number, row: number, hitDirection: CardinalDirection, tier4Heavy?: boolean): { destroyed: boolean; newMask: number; hitQuadrant: number }`:
     - If `tier4Heavy` is true: instantly destroys entire cell (`mask = 0b0000`, `type = EMPTY`).
     - Otherwise chips brick quadrants based on bullet travel direction (`CardinalDirection`):
       - UP bullet (moving UP, strikes from bottom): chips bottom quadrants (`BOTTOM_LEFT | BOTTOM_RIGHT`). If already chipped or empty, chips remaining top quadrants. If mask becomes 0, type becomes `EMPTY`.
       - DOWN bullet (strikes from top): chips top quadrants (`TOP_LEFT | TOP_RIGHT`). If already chipped, chips bottom quadrants.
       - LEFT bullet (strikes from right): chips right quadrants (`TOP_RIGHT | BOTTOM_RIGHT`). If already chipped, chips left quadrants.
       - RIGHT bullet (strikes from left): chips left quadrants (`TOP_LEFT | BOTTOM_LEFT`). If already chipped, chips right quadrants.
   - `damageSteel(col: number, row: number, tier4Heavy?: boolean): boolean`:
     - Standard shots cannot damage steel (returns false).
     - `tier4Heavy` destroys steel cell (sets `EMPTY`, returns true).
   - `damageEagle(): boolean`:
     - Marks `eagleState.destroyed = true`.
     - Changes the 2x2 cells at (12..13, 24..25) to destroyed state.
     - Returns true if state changed from intact to destroyed.
   - `isEagleDestroyed(): boolean`: Returns `eagleState.destroyed`.
   - `fortifyEagle(enableSteel: boolean): void`:
     - Perimeter cells around HQ: (11, 23), (12, 23), (13, 23), (14, 23), (11, 24), (14, 24), (11, 25), (14, 25).
     - If `enableSteel = true`: caches existing cells and sets perimeter to `STEEL` (mask `0b1111`).
     - If `enableSteel = false`: restores cached cells cleanly without leaving empty voids.
   - `queryRect(rect: Rect): TerrainQueryResult`:
     - Computes all overlapping cells between `rect` and grid.
     - Evaluates solidness (BRICK with mask > 0, STEEL, WATER, EAGLE).
     - Evaluates bulletSolid (BRICK with mask > 0, STEEL, EAGLE — WATER is not bulletSolid).
     - Evaluates terrain modifiers: `isIce` (any overlapping ICE cell), `isTrees` (any overlapping TREES cell).
   - `getIntersectingCells(rect: Rect): Array<{ col: number; row: number; cell: GridCell; overlapRect: Rect }>`:
     - Returns exact list of grid cells intersected by the given bounding box.
   - `getSubTileBoxes(col: number, row: number): Rect[]`:
     - Returns 0 to 4 bounding boxes (8x8px) for active sub-quadrants of a brick cell for fine-grained sub-pixel collision.
  </action>
