  <name>Task 2: Implement BulletManager with 120Hz Sub-Stepping, Cancellation, Terrain Damage & Tank Combat</name>
  <files>games/tank-1990/src/BulletManager.ts</files>
  <action>
    Create `games/tank-1990/src/BulletManager.ts` implementing `BulletManager` with:
    1. **State & Pooling**:
       - `bullets: Bullet[]` tracking active projectiles.
       - `nextBulletId: number = 1`.
       - `events: BulletHitEvent[]` capturing hit events for audio and particle emitters during frame updates.
       - `clearEvents()` to flush event queue each frame.
    2. **Firing API**:
       - `canFire(owner: BulletOwner, maxBullets: number): boolean` checking count of active bullets with matching `owner`.
       - `fire(x: number, y: number, direction: CardinalDirection, owner: BulletOwner, stats: { bulletSpeed: number, canDestroySteel: boolean, canCutTrees: boolean, damage?: number }, tankSize = 28): Bullet | null`:
         - Calculates muzzle spawn position centered on the tank face in `direction`:
           - UP: `x = tankX + (tankSize - BULLET_SIZE) / 2`, `y = tankY - BULLET_SIZE`
           - DOWN: `x = tankX + (tankSize - BULLET_SIZE) / 2`, `y = tankY + tankSize`
           - LEFT: `x = tankX - BULLET_SIZE`, `y = tankY + (tankSize - BULLET_SIZE) / 2`
           - RIGHT: `x = tankX + tankSize`, `y = tankY + (tankSize - BULLET_SIZE) / 2`
         - Instantiates `Bullet`, adds to active list, returns `Bullet`.
    3. **120Hz Sub-Stepping Simulation Loop**:
       - `update(dt: number, tanks: CombatTankTarget[] = []): BulletHitEvent[]`:
       - Fixed sub-step delta `const SUB_STEP_DT = 1 / 120` (~0.00833s).
       - Determine number of sub-steps: `const steps = Math.max(1, Math.ceil(dt / SUB_STEP_DT))`, `const stepDt = dt / steps`.
       - For each sub-step:
         - **Step 1: Move Bullets**: Advance `x` or `y` by `bullet.speed * stepDt` along `direction`.
         - **Step 2: Arena Boundary Collisions**: Check if bullet bounds exceed `[0, 0, ARENA_SIZE, ARENA_SIZE]`. If out of bounds, set `bullet.alive = false` and emit `'BOUNDARY'` event at collision edge.
         - **Step 3: Mid-Air Bullet-vs-Bullet Cancellation (COMBAT-02)**:
           - Check pair-wise AABB overlap between all active `PLAYER` bullets and active `ENEMY` bullets.
           - If two opposing bullets intersect: set both `alive = false`, emit `'BULLET_CANCEL'` event at midpoint `((b1.x + b2.x)/2, (b1.y + b2.y)/2)`.
         - **Step 4: Bullet-vs-Terrain Collisions (COMBAT-03)**:
           - Query intersecting cells via `grid.getIntersectingCells(bulletBounds)`.
           - For each cell intersected:
             - If `BRICK`: call `grid.damageBrick(col, row, bullet.direction, bullet.canDestroySteel)`. If quadrants damaged/destroyed, mark `bullet.alive = false`, emit `'BRICK'` event.
             - If `STEEL`: if `bullet.canDestroySteel`, call `grid.damageSteel(col, row, true)` destroying steel. Bullet always destroyed (`alive = false`), emit `'STEEL'` event.
             - If `TREES`: if `bullet.canCutTrees`, clear tile `grid.setCell(col, row, TileType.EMPTY, SubTileMask.EMPTY)`, mark `bullet.alive = false`, emit `'TREE'` event. If not `canCutTrees`, bullet flies through without colliding.
             - If `WATER`: bullet flies through without colliding (`bulletSolid = false`).
             - If `ICE`: bullet flies through without colliding.
             - If `EAGLE`: call `grid.damageEagle()`, mark `bullet.alive = false`, emit `'EAGLE'` event.
         - **Step 5: Bullet-vs-Tank Damage Resolution (COMBAT-04)**:
           - For each live bullet:
             - Check AABB overlap with `tanks`:
               - If `bullet.owner === 'PLAYER'`, only collide with enemy tanks (`!tank.isPlayer`).
               - If `bullet.owner === 'ENEMY'`, only collide with player tank (`tank.isPlayer`).
             - If collision occurs and `!tank.isDead`:
               - If `tank.isInvulnerable`: bullet is absorbed (`bullet.alive = false`), emit `'TANK'` event with zero damage.
               - Else: call `tank.takeDamage(bullet.damage)`, mark `bullet.alive = false`, emit `'TANK'` event.
       - Filter out dead bullets: `this.bullets = this.bullets.filter(b => b.alive)`.
       - Return accumulated `events`.
    4. **Utility Methods**:
       - `getBullets(): Bullet[]` returns current live projectiles.
       - `clear()` removes all bullets and events.
