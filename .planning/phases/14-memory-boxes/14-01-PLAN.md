<task type="auto" tdd="true">
  <name>Task 2: Implement GameState turn state machine, life tracking, speed bonus calculation, and unit tests</name>
  <files>
    games/memory-boxes/src/GameState.ts,
    games/memory-boxes/test/gamestate.test.ts
  </files>
  <behavior>
    - Status transitions: `ready` -> `playback` -> `player_turn` -> `round_complete` / `gameover`. Support `paused`.
    - Life tracking: 3 lives maximum. Wrong step deducts 1 life. If lives remain, re-enter playback or allow retry of current round. If 0 lives, transition to `gameover`.
    - Player step validation: `submitStep(boxId: number)` compares against `sequence[playerStepIndex]`.
    - Scoring: Base round score (e.g. 500 * round), plus speed bonus based on player response time, plus streak multiplier.
    - High score: Persist to localStorage via `saveData` and call `reportScore`.
  </behavior>
  <action>
    1. Implement `GameState.ts`:
       - `export type GameStatus = 'ready' | 'playback' | 'player_turn' | 'round_complete' | 'paused' | 'gameover';`
       - `public static readonly INITIAL_LIVES = 3;`
       - `public static readonly BASE_ROUND_SCORE = 500;`
       - `public static readonly MAX_ROUND_TIME = 15.0;`
       - `public static readonly STORAGE_KEY = 'memory-boxes-highscore';`
       - Fields: `score`, `highScore`, `round`, `lives`, `status`, `playerStepIndex`, `roundTimer`, `streak`.
       - Methods:
         - `start()`: resets round to 1, score to 0, lives to 3, initializes sequence, starts `playback`.
         - `startPlayerTurn()`: switches status to `player_turn`, resets `playerStepIndex` and `roundTimer`.
         - `submitStep(boxId: number): { correct: boolean; roundCompleted: boolean; gameOver: boolean; pointsAwarded: number }`
         - `update(dt: number)`: decrements `roundTimer` during `player_turn`. If timer expires, deduct life as a mistake.
         - `pause()`, `resume()`, `restart()`
         - `finalizeGame()`: saves high score with `saveData`, reports score with `reportScore`.
    2. Write unit tests in `games/memory-boxes/test/gamestate.test.ts` covering:
       - Initialization and saved high score loading.
       - Successful round sequence matching advancing rounds and awarding speed points.
       - Incorrect step deduction of lives and game over trigger at 0 lives.
       - Round timer expiration deducting life.
       - Pause/resume state handling.
  </action>
