  <behavior>
    - BoxRenderer: Calculates 3x3 responsive box bounds on 800x600 canvas. Renders rounded neon boxes with idle border glow, active radial highlight fill, inner icon/symbol, and pulse fade transitions.
    - AudioPitches (TonePlayer): Web Audio API oscillator synthesis generating custom frequency sine/triangle tones with gentle ADSR envelopes for each box pitch without audio clipping or memory leaks. Also provides win fanfare and error buzz tones.
    - ParticleSystem: Emits radial burst particles and expanding wave rings on box tap / sequence success.
    - Tests verify particle lifecycles, velocity decay, and system reset.
  </behavior>
  <action>
    1. Implement `BoxRenderer.ts`:
       - `getGridDimensions(canvasWidth: number, canvasHeight: number)`: calculates box size (e.g. 110x110), padding, and offsets to center 3x3 matrix in canvas.
       - `getBoxBounds(box: Box, dims: GridDimensions)`: returns `{ x, y, w, h }`.
       - `renderBox(ctx: CanvasRenderingContext2D, box: Box, dims: GridDimensions)`:
         - Draws background box container with dark metallic cyber background (`#0f172a`).
         - Computes glow intensity based on `box.activeIntensity` (0 to 1).
         - When active: draws radiant inner glow, bright neon border (`ctx.shadowBlur = 18`), and intense color fill.
         - When idle: draws subtle neon outline with soft border glow.
    2. Implement `AudioPitches.ts` (`TonePlayer`):
       - Uses Web Audio API AudioContext with master gain and mute support (respecting `arcade-carnival-muted`).
       - `playTone(frequency: number, duration: number = 0.25)`: creates oscillator (sine/triangle), sets frequency, ramps gain smoothly (attack 0.02s, decay 0.23s).
       - `playError()`: low-frequency dissonance buzz.
       - `playRoundComplete()`: rising triad flourish.
       - `playGameOver()`: descending buzz tone.
    3. Implement `Particles.ts`:
       - Burst particles + expanding shockwave ring effects.
       - `emit(x, y, count, color, speed, size, maxLife)`
       - `emitRing(x, y, radius, color, maxLife)`
       - `update(dt)` and `render(ctx)`
    4. Write unit tests `games/memory-boxes/test/particles.test.ts`.
  </action>
