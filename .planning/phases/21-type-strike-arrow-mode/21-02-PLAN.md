  <action>
    1. In `games/type-strike/src/TypeStrikeScene.ts`:
       - Add `mode: GameMode = 'words';` property to `TypeStrikeScene`.
       - Define mode toggle button bounding box: `modeToggleRect = { x: 260, y: 400, width: 280, height: 44 };`.
       - Add `toggleMode(): void` method:
         - Flips `this.mode` between `'words'` and `'arrows'`.
         - Updates `this.typingEngine.setMode(this.mode)`.
         - Plays `audio.playClick()`.
       - Update `handleKeyDown(e: KeyboardEvent)`:
         - In `'ready'` state:
           - If `e.key === 'm' || e.key === 'M' || e.key === 'Tab'`: prevent default and call `toggleMode()`.
           - If `e.code === 'Space' || e.code === 'Enter'`: start game.
           - If in `'words'` mode and key is letter 'a'-'z'/'A'-'Z': start game and process key.
           - If in `'arrows'` mode and key is Arrow or WASD: start game and process key.
         - In `'playing'` state:
           - Pass `e.key` to `this.typingEngine.handleKey(e.key, this.enemies, this.mode)`.
           - In Arrow keys case, call `e.preventDefault()` to avoid scrolling page.
       - Update `handlePointerDown(e: PointerEvent)`:
         - In `'ready'` state:
           - Get canvas bounding rect and mouse coordinates `(x, y)`.
           - If `(x, y)` is within `this.modeToggleRect`: call `this.toggleMode()`, do NOT start game.
           - Else: start game.
       - Update `spawnDrone(elapsed, speed)`:
         - Pass `this.mode` to `this.dictionary.getRandomWord(activeWords, tier, this.mode)`.
         - Create `Enemy` with `mode: this.mode`.
       - Update `render(ctx)`:
         - In drone rendering loop:
           - If `enemy.mode === 'arrows'`, format matched and unmatched sequences with arrow symbols (e.g. `'↑ '` and `'↓ ← →'`) using `arrowCharToSymbol`.
           - Adjust badge width dynamically for arrow spacing.
           - Draw arrow symbols with cyan glow for matched and white for remaining. Underline next target arrow if locked.
         - In bottom tactical status bar:
           - Format locked target and next target symbol using `arrowCharToSymbol` in Arrow mode.
         - In `renderReadyOverlay(ctx)`:
           - Render mode toggle button `[MODE: WORDS]` or `[MODE: ARROWS (↑↓←→)]` with glowing neon border and hover/interactive cue.
           - Render subtitle instructions corresponding to mode:
             - Words: `"Type prompt words above approaching drones to fire lasers."`
             - Arrows: `"Press Arrow keys (↑↓←→) or WASD to clear direction sequences and fire lasers."`
           - Add hint: `"Press [M] / [TAB] or Click Button to Toggle Mode"`.
  </action>
