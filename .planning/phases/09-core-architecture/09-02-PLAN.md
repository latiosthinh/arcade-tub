  <name>Task 2: Implement Zero-Dependency HashRouter with Unit Tests</name>
  <files>src/core/Router.ts, test/core/router.test.ts</files>
  <behavior>
    - Test 1: Router registers static routes and dispatches matching handler when hash changes
    - Test 2: Router registers parameterized routes (e.g. /game/:id) and extracts decoded params object
    - Test 3: Router triggers notFound handler when navigating to an unregistered route
    - Test 4: navigate() updates window.location.hash formatted with leading #
    - Test 5: stop() cleans up hashchange/popstate event listeners preventing test pollution
  </behavior>
  <action>
    1. Create `src/core/Router.ts`:
       - Define `type RouteHandler = (params: Record<string, string>) => void | Promise<void>`
       - Define `interface RouteRule { pattern: RegExp; paramNames: string[]; handler: RouteHandler }`
       - Implement `class HashRouter`:
         - `private routes: RouteRule[] = []`
         - `private notFoundHandler: RouteHandler = () => {}`
         - `private listener: (() => void) | null = null`
         - `public on(path: string, handler: RouteHandler): this` compiling `:param` segments into capturing regex groups.
         - `public notFound(handler: RouteHandler): this` registering fallback handler.
         - `public navigate(hashOrPath: string): void` setting `window.location.hash`.
         - `public start(useTransitions = false): void` registering `hashchange` listener and dispatching current hash immediately (defaulting to `#/` if empty).
         - `public stop(): void` removing active event listener.
         - `public resolve(hash?: string): void` resolving route against registered rules and invoking handler (optionally with `transitionView`).
    2. Create `test/core/router.test.ts` with comprehensive coverage of routing, param parsing, transitions, notFound fallback, and listener teardown.
  </action>
