  <behavior>
    - Fish entity:
      - Properties: `x` (number, fixed horizontal position e.g. 160), `y` (number, vertical position e.g. 300), `vy` (vertical velocity px/s), `radius` (hitbox radius e.g. 18), `width` (render width e.g. 44), `height` (render height e.g. 32), `rotation` (radians, pitch angle), `gravity` (e.g. 980 px/s²), `drag` (water damping factor e.g. 0.98), `flapImpulse` (e.g. -380 px/s), `maxFallSpeed` (e.g. 600 px/s), `maxRiseSpeed` (e.g. -450 px/s), `finPhase` (oscillation phase for fin animation).
      - Physics & Controls:
        - `flap()`: Applies negative vertical impulse (`vy = flapImpulse`), resets fin animation burst, clamps `vy >= maxRiseSpeed`.
        - `update(dt: number)`:
          - Applies gravity: `vy += gravity * dt`.
          - Applies water drag deceleration: `vy *= Math.pow(drag, dt * 60)`.
          - Clamps `vy` to `maxFallSpeed`.
          - Integrates position: `y += vy * dt`.
          - Calculates pitch angle: maps `vy` to `[-0.45, 1.1]` radians (swims upward ~ -25 deg, dives down ~ +65 deg) using smooth interpolation.
          - Advances `finPhase += dt * (8 + Math.abs(vy) * 0.02)`.
        - `checkBounds(minY: number, maxY: number)`: Returns `'top'` if `y - radius <= minY`, `'bottom'` if `y + radius >= maxY`, or `null`.
        - `reset(startX: number, startY: number)`: Resets position, velocities, rotation, and animation timers.
  </behavior>
  <action>

    3. Implement `Fish.ts`:

  <behavior>
    - PipeManager:
      - Manages scrolling pairs of top and bottom coral reef pillars.
      - Properties per `CoralPillar`: `id`, `x`, `width` (e.g. 70px), `topHeight`, `bottomY`, `gapSize` (e.g. 150px), `passed` (boolean), `hasPearl` (boolean), `pearlCollected` (boolean), `pearlX`, `pearlY`, `pearlRadius` (12px).
      - Spawning: `spawnPillar(canvasWidth: number, canvasHeight: number)` creates new pillar pair offscreen right with randomized gap center (within safe bounds e.g. 120px to canvasHeight - 120px) and ~30% chance to spawn a bonus pearl bubble centered in the gap.
      - Scrolling: `update(dt: number, speedMultiplier: number)` moves all pillars left by `speed * dt` (e.g. base speed 180 px/s), removes offscreen pillars, and spawns new pairs when distance threshold reached.
      - Collision Detection:
        - `checkPillarCollision(fish: Fish)`: Tests fish circle against top pillar AABB `[x, 0, width, topHeight]` and bottom pillar AABB `[x, bottomY, width, canvasHeight - bottomY]`. Returns true on intersection.
        - `checkScoreTriggers(fish: Fish)`: Detects when fish passes pillar center (`fish.x > pillar.x + pillar.width / 2` and `!pillar.passed`), marks `pillar.passed = true`, and returns count of newly passed pillars.
        - `checkPearlCollisions(fish: Fish)`: Detects circle-circle collision between fish and active pearl bubbles (`distance <= fish.radius + pearlRadius`), collects pearl, and returns collected count.
    - GameState:
      - Status machine: `ready` -> `playing` -> `paused` -> `gameover`.
      - Score metrics: `score` (coral gates passed), `pearls` (bonus pearl count, e.g. +3 score or separate currency), `highScore`, `totalScore` (`score + pearls * 3`), `medal` (`'none' | 'bronze' | 'silver' | 'gold' | 'platinum'`).
      - Medal thresholds: bronze >= 10, silver >= 25, gold >= 50, platinum >= 100 total score.
      - Storage: Saves and loads high score via `loadData`/`saveData` with storage key `arcade-carnival-flappy-fish-highscore` and reports score with `reportScore`.
  </behavior>
