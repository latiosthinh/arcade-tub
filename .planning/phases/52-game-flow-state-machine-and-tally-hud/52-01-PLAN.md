  <files>games/tank-1990/src/GameFlow.ts</files>
  <action>
    Create `games/tank-1990/src/GameFlow.ts`:
    1. Properties & Lifecycle:
       - `state: GameState = GameState.TITLE`
       - `currentStage: number = 1` (clamped 1 to `TOTAL_STAGES` = 35)
       - `curtainTimer: number = 0` (duration 2.0s for stage intro curtain slide)
       - `curtainDuration: number = 2.0`
       - `tallyTimer: number = 0`
       - `tallyDuration: number = 3.5` (time for animated points roll-up)
       - `gameOverTimer: number = 0`
       - `selectedTitleOption: TitleOption = TitleOption.ONE_PLAYER`
       - `scoreManager: ScoreManager`
    2. State Machine Transitions (LOOP-01, LOOP-02, LOOP-05):
       - `goToTitle()`: Sets `state = TITLE`, resets selected option.
       - `selectStage(stageNumber: number)`: Clamps stage between 1 and `TOTAL_STAGES`.
       - `startStage(stageNumber?: number)`: Sets `currentStage = stageNumber ?? currentStage`, sets `state = STAGE_INTRO`, resets `curtainTimer = curtainDuration`, resets stage kills in `ScoreManager`.
       - `pause()` / `resume()` / `togglePause()`: Toggles between `PLAYING` and `PAUSED` (only valid when in `PLAYING` or `PAUSED`).
       - `triggerGameOver()`: Sets `state = GAME_OVER`, resets `gameOverTimer = 0`.
       - `triggerVictory()`: Sets `state = VICTORY`.
       - `onStageCleared()`: Transitions `state = STAGE_TALLY`, resets `tallyTimer = 0`.
       - `nextStage()`: If `currentStage >= TOTAL_STAGES`, calls `triggerVictory()`. Else increments `currentStage++` and calls `startStage(currentStage)`.
       - `restart()`: Resets `currentStage = 1`, resets game score, calls `startStage(1)`.
    3. Update Loop & Timer Coordination:
       - `update(dt: number)`:
         - When `state === STAGE_INTRO`: Decrement `curtainTimer`. When `curtainTimer <= 0`, transition `state = PLAYING`.
         - When `state === STAGE_TALLY`: Increment `tallyTimer`.
         - When `state === GAME_OVER`: Increment `gameOverTimer`.
    4. HUD and Display Helpers (LOOP-02, LOOP-03):
       - `getCurtainProgress(): number`: Returns normalized progress `1.0 - (curtainTimer / curtainDuration)` (clamped 0 to 1).
       - `getTallyProgress(): number`: Returns normalized tally roll-up progress.
       - `getHUDState(enemyReserveCount: number, playerLives: number, playerTier: TankTier): HUDState`:
         - Returns snapshot `{ stage: this.currentStage, lives: playerLives, score: this.scoreManager.score, highScore: this.scoreManager.highScore, enemyReserveCount, playerTier, isGameOver: this.state === GameState.GAME_OVER, isPaused: this.state === GameState.PAUSED }`.
