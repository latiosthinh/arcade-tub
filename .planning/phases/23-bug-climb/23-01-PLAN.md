  <behavior>
    - TreeTrunk:
      - `BranchSide` enum: `NONE = 'NONE'`, `LEFT = 'LEFT'`, `RIGHT = 'RIGHT'`.
      - `TrunkSegment` interface: `id: number`, `altitude: number`, `branch: BranchSide`, `woodVariation: number`.
      - Constants: `VISIBLE_SEGMENTS = 8`, `SEGMENT_HEIGHT = 80`, `SAFE_START_SEGMENTS = 4`.
      - State: `segments: TrunkSegment[]`, `nextAltitude: number`.
      - Methods:
        - `generateInitial(count?: number): void` -> fills segment buffer. First `SAFE_START_SEGMENTS` have `BranchSide.NONE`. Subsequent segments randomly spawn `NONE`, `LEFT`, or `RIGHT` while guaranteeing no impossible configurations (e.g., branches do not repeat continuously more than 4 times on the same side without break, never both sides on same segment).
        - `step(): TrunkSegment` -> shifts bottom segment off, generates and pushes new top segment, increments `nextAltitude`. Returns the removed bottom segment.
        - `getBranchAt(index: number): BranchSide` -> returns branch side for segment index (0 = climber base height, 1 = segment directly above climber, etc.).
        - `reset(): void`.
    - BugClimber:
      - `ClimberSide` enum: `LEFT = 'LEFT'`, `RIGHT = 'RIGHT'`.
      - `ClimbResult` interface: `{ success: boolean, collided: boolean, branchHit: BranchSide, climbedAltitude: number }`.
      - State: `side: ClimberSide`, `altitude: number`, `scurryTimer: number`, `alive: boolean`.
      - Methods:
        - `climb(targetSide: ClimberSide, trunk: TreeTrunk): ClimbResult`:
          - Updates `side = targetSide`.
          - Advances trunk with `trunk.step()`.
          - Checks segment at climber position (index 0 or immediate branch check at current height). If `trunk.getBranchAt(0) === targetSide`, `collided = true`, `alive = false`.
          - If collided, `success = false`. Otherwise `success = true`, `altitude += 1`, `scurryTimer = 0.12`.
          - Returns `ClimbResult`.
        - `update(dt: number): void` -> decrements `scurryTimer`.
        - `reset(initialSide?: ClimberSide): void`.
  </behavior>

    - UrgentTimer:
      - Constants: `DEFAULT_MAX_TIME = 8.0`, `INITIAL_TIME = 5.0`, `TIME_BONUS_PER_STEP = 0.28`, `BASE_DRAIN_RATE = 1.0`.
      - State: `timeRemaining: number`, `maxTime: number`, `drainRate: number`, `isUrgent: boolean` (true when time < 25% of maxTime).
      - Methods:
        - `update(dt: number, altitude: number = 0): { expired: boolean, isUrgent: boolean }`:
          - Calculates dynamic drain speed: `drainRate = BASE_DRAIN_RATE + Math.min(2.5, altitude * 0.015)`.
          - Decrements `timeRemaining -= drainRate * dt`.
          - Clamps `timeRemaining = Math.max(0, timeRemaining)`.
          - Returns `{ expired: timeRemaining <= 0, isUrgent: timeRemaining <= maxTime * 0.25 }`.
        - `addStepBonus(bonus?: number): void` -> adds `bonus ?? TIME_BONUS_PER_STEP`, clamped to `maxTime`.
        - `getTimeFraction(): number` -> returns `timeRemaining / maxTime` (0.0 to 1.0).
        - `reset(): void`.
    - GameState:

        - `addClimbScore(): number` -> adds `10 * multiplier` to `score`, increments `altitude` and `stepsClimbed`, resets `streakTimer = 0.8`, updates `highScore`.
        - `update(dt: number): void` -> updates streak timer and resets streak when expired.
        - `startGame()`, `pause()`, `resume()`, `endGame(reason: 'collision' | 'timeout')`, `reset()`.
