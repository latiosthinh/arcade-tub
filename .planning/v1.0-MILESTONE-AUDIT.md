## 2. Cross-Phase Integration & Wiring

- **Hub to Games Integration:** `src/hub.ts` maps all 5 game slugs (`safe-cracker`, `brick-blitz`, `sky-hopper`, `crate-catch`, `type-strike`), pulls persistent high scores through `@arcade-carnival/playables-adapter`, and links to `/games/{slug}/index.html`. Floating "Back to Hub" nav links present in each game HTML.
- **Shared Playables Adapter:** All 5 game entry points initialize the adapter with `initPlayables()`, forward YouTube lifecycle events (`onPause`, `onResume`), persist high scores (`saveData`, `loadData`), and report scores (`reportScore`).
- **Shared Game Engine:** Fixed 60fps `GameLoop`, unified `InputManager`, and `SceneManager` power all 5 game scenes with responsive canvas resizing and input tracking.
- **Procedural Web Audio:** `packages/game-engine` exports singleton `audio` (`AudioSynthesizer`). 38 sound triggers wired across all 5 games with zero external audio assets and global mute state synced with localStorage.
