# Roadmap: Arcade Carnival

## Overview

Arcade Carnival delivers 5 browser-based HTML5 Canvas arcade minigames packaged for YouTube Playables with a shared game engine, playables adapter, and central launcher. Milestone v1.0 shipped all 5 games and infrastructure. Milestone v2.0 overhauled the webapp with a custom retro-modern cyber-arcade design system, lightweight component architecture, client-side routing, responsive mobile-first navigation, and procedural UI audio.

## Milestones

- [x] **v1.0: Arcade Carnival Core** - 5 canvas games, playables adapter, game engine, and hub shell (Shipped 2026-08-17)
