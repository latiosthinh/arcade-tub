# Roadmap: Arcade Carnival

## Overview

Arcade Carnival delivers 12 browser-based HTML5 Canvas arcade minigames with a shared game engine, playables adapter, and central cyber-arcade launcher. Milestone v3.0 expanded the game library to 12 complete, playable games with procedural audio, standalone builds, and persistent high scores.

## Milestone v3.0 Phases (Complete)

- [x] **Phase 13: Memory Cards Minigame** — Card flip matching, streak combos, timer, sound & scores
- [x] **Phase 14: Memory Boxes Minigame** — Pattern sequence memory, neon light pulses, audio tones
- [x] **Phase 15: Pop Balloon Minigame** — Ascending neon balloon clicker, color combo chain, hazard spike bombs
- [x] **Phase 16: Space Racer Minigame** — Warp starfield flight, asteroid dodging, turbo boost gates
- [x] **Phase 17: Virus Defense Minigame** — 360° turret targeting, projectile physics, pathogen swarm defense
- [x] **Phase 18: Flappy Fish Minigame** — Hydrodynamic flap physics, glowing coral reef barriers, bubble collection
- [x] **Phase 19: 2048 Neon Minigame** — 4x4 sliding number tile puzzle, merge animations, touch swipe controls
- [x] **Phase 20: Catalog Integration & Release Audit** — Hub registration, SVG screenshots, multi-page Vite build, size audit (<200KB)
